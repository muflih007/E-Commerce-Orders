## Turning E-Commerce Orders Data into Actionable Business Insights 
An interactive E-Commerce Orders and Sales Performance Dashboard developed using Microsoft Power BI to analyse order trends, customer behaviour, sales performance, and sales target achievement.

This project transforms order and sales-related data into interactive visual reports that help identify business trends, monitor performance, and support data-driven decision-making.

Tools: Power BI • DAX • Power Query • Data Visualization

## Project Overview :

E-commerce businesses generate valuable data through customer orders, sales transactions, order channels, and sales activities. Analysing this information helps businesses understand their performance and identify areas that require improvement.

In this project, I developed an interactive Power BI dashboard to explore order information, customer characteristics, geographical sales performance, and sales target completion.

The report contains four analytical pages:

Sales Team: Sales team, sales manager, and sales POC performance.
Orders: Order trends, order values, customer-related information, and order sources.
Sales Target: Sales target monitoring and performance comparisons.
SM Sales by Country: Geographical sales analysis and sales manager comparisons.

The dashboard provides a consolidated view of different aspects of sales operations and enables users to explore the data through interactive report visuals and filters.
